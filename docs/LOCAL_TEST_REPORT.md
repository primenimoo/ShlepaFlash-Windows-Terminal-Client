# Локальный отчёт проверок релиза 1.0.0

Проверено в рабочей среде сборки артефакта:

- `python -m compileall -q src tests` — успешно.
- `python -m pytest -q tests/test_core.py tests/test_api.py` — 18 тестов успешно.
- `tests/test_flasher.py` вместе с core/API — 22 теста успешно; в локальной среде модуль pyserial заменялся изолированной заглушкой для COM-портов, потому что pyserial/esptool/Textual не установлены и сетевой доступ к пакетному индексу недоступен.
- `python -m pip wheel --no-deps --no-build-isolation .` — wheel собран успешно.
- Проверена AST-компиляция исходников, наличие обязательных файлов и структура PowerShell here-string.
- UI-тесты в `tests/test_app.py` включены в GitHub Actions, где устанавливаются все зависимости; в текущей среде они не запускались из-за отсутствующего пакета Textual и недоступного DNS.
- PowerShell parser check включён в GitHub Actions (`windows-latest`) и не был выполнен локально, так как PowerShell отсутствует в текущей среде.
- Реальная прошивка физического устройства не выполнялась: аппаратное устройство не подключено. Перед использованием на устройстве нужен тест с конкретной моделью и известным корректным файлом прошивки.

Это отчёт о фактически выполненных проверках, не заявление о том, что физическое устройство уже прошито или что удалённый Windows UI был испытан на каждой версии Windows.
